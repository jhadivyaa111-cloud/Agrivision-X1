# AgriVision X1 🌱🚁

Interactive 3D product showcase for an AI-powered smart agriculture drone.

## Features
- Interactive 3D drone
- Drag to rotate
- Scroll/pinch to zoom
- Auto-rotation
- Animated propellers
- AI Scan interaction
- Four product information controls
- Responsive design
- GitHub Pages ready

## Run locally
Open `index.html` with a local server. Because Three.js is imported as an ES module, a local server is recommended.

Example:
`python -m http.server 5500`

Then visit `http://localhost:5500`.

## Deploy
Upload all files to a GitHub repository and enable GitHub Pages from Settings → Pages.
